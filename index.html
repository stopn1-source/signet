사용법

1. 주제찾기
관심 분야, 희망 진로, 관련 과목(선택)을 입력하고 "주제 추천받기"를 누르면 탐구 주제를 1개 추천해드려요. 마음에 안 들면 버튼을 다시 눌러보세요 — 이전과 겹치지 않는 새 주제로 다시 추천해드려요.

2. 탭 활용
추천받은 주제는 ①개요 ②탐구내용 ③참고자료 세 탭으로 나뉘어요. ②탐구내용에는 관련 수식(표로 정리)과, 확정적 함수면 직접 계산한 그래프 또는 실제 데이터로 그린 그래프(출처 표시)도 같이 나와요. 내용이 길면 1·2·3 같은 페이지 번호로 나눠서 보여드려요. ②③은 탭을 누르는 순간 불러오기 시작해요.

3. 찜
마음에 드는 주제는 하트(🤍)를 눌러 찜해두세요. 마이홈의 "찜"에서 과목별로 모아볼 수 있고, 각 주제마다 탐구 진행 체크리스트(주제 확정 → 자료조사 → 계획수립 → 실험/조사 → 결과정리 → 초안작성 → 피드백반영 → 제출)로 진행 상황을 관리할 수 있어요.

4. 전체 기록
찜하지 않은 주제도 최근 100개까지 자동으로 기록에 남아요.

5. 과제 마감
학교에서 받은 과제와 마감일을 등록해두면, 마이홈 첫 화면에 D-day로 보여줘요.

6. 예상질문
찜한 주제를 불러오거나 직접 입력하고, 지원 학과까지 적으면 면접 예상 질문과 답변 예시(Q&A)를 만들어드려요. 답변은 그대로 외우지 말고 연습용 예시로만 참고하세요.

7. 탐구 연계하기
이미 탐구한 주제와 과목, 새로 연계하고 싶은 과목을 입력하면 연계 주제를 추천해드려요. 여러 과목에서 같은 관심사를 꾸준히 파고들었다는 걸 보여주는 데 좋은 전략이에요. 만든 연계 주제는 "연계 탐구 모아보기"에서 찜하지 않아도 원본별로 묶어서 볼 수 있어요.

8. 용어 사전
탐구 주제를 넣으면 대학 전공서적 수준의 전문 용어를 영어 표기와 함께 정리해드려요. 나중에 원서·논문을 볼 때도 도움이 돼요.

9. 커뮤니티
관심사별로 방을 만들어서 다른 학생들과 이야기할 수 있어요. 같은 방 이름으로 글을 쓰면 한 방에 모여요. 실명이나 연락처는 적지 마시고, 부적절한 글은 🚩 신고 버튼으로 알려주세요.

10. 프로필 아바타
마이페이지에서 동물 이모지 중 하나를 골라 프로필로 쓸 수 있어요. 실제 사진은 업로드하지 않아요.

11. 계정 관리
마이페이지에서 비밀번호 변경, 아이디 변경(중복확인 포함)이 가능해요. 아이디를 바꿔도 찜·기록·과제·게시글은 그대로 유지돼요.

12. 화면 설정
다크모드, 색깔(10종), 글씨체(8종)를 마이페이지에서 바꿀 수 있어요.

주의
주제랑 탐구 방향까지만 알려드려요. 보고서 문장은 직접 쓰셔야 하고, 실제 학교생활기록부(생기부) 원문은 절대 넣지 마세요. 사실 정확성을 위해 노력하지만, 구체적인 수치나 인용은 항상 원문을 찾아 다시 확인해보세요.

아직 테스트 중인 서비스예요. 실제 학교생활기록부(생기부) 원문은 넣지 마세요 — 생기부에 반영되기 전, 탐구할 주제를 찾는 것까지만 도와드려요.
